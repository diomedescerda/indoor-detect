# Borradores y documentación congelada de anotación

[Inicio](../../README.md) · [Guía del material auxiliar](../README.md) · [Estudio vigente](../../Build/Testing/README.md)

`Testing/README.md` y sus verificadores originales son archivos históricos
protegidos por las sumas del paquete base. Sus rutas y comandos corresponden a
la ubicación anterior: no utilizarlos como guía de ejecución actual ni modificar
sus bytes para corregir enlaces. `development/relocations.json` permite comprobar
su identidad después del traslado.

Para reproducir el estudio final, seguir la [guía actual](../../docs/REPRODUCIR.md).
Las fotos y `labels.json` revisado permanecen en `Build/Testing/`.
`occlusion/` contiene el visor opcional de etiquetas suplementarias; su
[protocolo actual](../../Build/Testing/occlusion/README.md) indica cómo revisar,
exportar y recalcular en una carpeta nueva.
