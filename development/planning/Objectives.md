#### General Objective
* Develop an assistance system implemented on a mobile device, based on computer vision techniques, for the identification and spatial localization of objects in indoor environments, aimed at supporting environmental perception for people with visual disabilities.

###### Specific Objectives
* Select an object detection model optimized for implementation on mobile devices with Android platform.
* Develop a functional prototype on Android platform that integrates the device camera and an object detection model to identify elements of the environment and determine their relative location, as well as audio descriptors.
* Evaluate the prototype's performance in controlled indoor environments, analyzing metrics such as detection accuracy, processing latency, and clarity of auditory feedback.
